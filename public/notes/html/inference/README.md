# Chapters 2–3 Study Guide

打开 `index.html` 开始阅读。正文位于 `pages/`，每个模块独立成页；无需服务器或联网。复制到另一台电脑时请复制整个文件夹，以保留公式字体、样式、搜索和交互功能。

## 阅读顺序

- 00：Overall Concepts List，集中复习术语、例子和易错边界。
- 01–12：完整的概率、统计推断与回归衔接主线。
- 13：Bootstrap 与论文联系，明确标注延伸范围。
- 14：19 道综合练习及折叠解答。
- 15：三个教材 empirical exercise 的分析路径，以及自包含的示例。
- 16：符号、公式与易错点。
- 17：来源、章节覆盖表及原材料更正。

学术定义、定理、推导、问题和解答用英文；直觉与通俗解释用中文。数学使用标准 LaTeX 并由本地 KaTeX 离线渲染。网页支持全书搜索、离线 Bernoulli 抽样演示、可持久保存的模块阅读标记和打印。

## 文件结构

```
index.html              阅读入口
pages/                  18 个 HTML 阅读页面
assets/                 本地 CSS、字体、公式渲染、交互与搜索资源
```

本文件夹只面向阅读者。可维护正文、来源记录与构建方法已经分离到课程根目录的 `90 Agent Workspace`，避免最终笔记与制作文件混在一起。
